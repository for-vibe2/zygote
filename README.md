# Zygote C Compiler

Примитивный C компилятор, написанный полностью на ассемблере x86_64. Это образовательный проект, демонстрирующий основные принципы построения компиляторов.

## 📋 Описание

Zygote - это простой компилятор для подмножества языка C, реализованный полностью на ассемблере x86_64 (синтаксис AT&T). Проект создан для изучения внутреннего устройства компиляторов и низкоуровневого программирования.

### Особенности

- ✅ Написан полностью на x86_64 assembly
- ✅ Многопроходная архитектура компилятора
- ✅ Лексический анализатор (токенизация)
- ✅ Синтаксический анализатор (построение AST)
- ✅ Генератор кода (вывод x86_64 asm)
- ✅ Поддержка базового подмножества C
- ✅ Система сборки через Makefile
- ✅ Примеры программ

### Поддерживаемое подмножество C

**Типы данных:**
- `int` - целочисленный тип

**Операторы:**
- Объявление переменных
- Присваивание
- Арифметические операции (+, -, *, /)
- Оператор return
- Условные операторы (if/else) - частично
- Циклы (while) - частично

**Функции:**
- Определение функции main
- Параметры функций - в разработке
- Локальные переменные

## 🏗️ Архитектура

Компилятор следует классической многопроходной архитектуре:

```
Исходный код C
      ↓
┌─────────────────┐
│  Лексический    │  lexer.s
│  анализатор     │  Токенизация исходного кода
│  (Lexer)        │
└─────────────────┘
      ↓
   [Токены]
      ↓
┌─────────────────┐
│  Синтаксический │  parser.s
│  анализатор     │  Построение AST
│  (Parser)       │
└─────────────────┘
      ↓
     [AST]
      ↓
┌─────────────────┐
│  Генератор      │  codegen.s
│  кода           │  Генерация x86_64 asm
│  (CodeGen)      │
└─────────────────┘
      ↓
  Assembly код
```

### Компоненты

1. **main.s** - Главный драйвер компилятора
   - Обработка аргументов командной строки
   - Чтение/запись файлов
   - Координация всех фаз компиляции

2. **lexer.s** - Лексический анализатор
   - Разбивает исходный код на токены
   - Распознает ключевые слова, идентификаторы, числа, операторы
   - Пропускает пробелы и комментарии

3. **parser.s** - Синтаксический анализатор
   - Строит абстрактное синтаксическое дерево (AST)
   - Рекурсивный нисходящий парсер
   - Проверяет синтаксическую корректность

4. **codegen.s** - Генератор кода
   - Обходит AST и генерирует x86_64 ассемблер
   - Управление регистрами
   - Генерация меток и переходов

## 🚀 Установка и сборка

### Требования

- Linux x86_64
- GNU Assembler (as)
- GNU Linker (ld)
- GNU Make

### Сборка

```bash
# Клонировать репозиторий или перейти в директорию проекта
cd compiler

# Собрать компилятор
make

# Или с очисткой предыдущей сборки
make clean all
```

### Проверка сборки

```bash
# Проверить что компилятор собран
ls -lh zygote-cc

# Посмотреть размеры файлов
make sizes

# Статистика проекта
make stats
```

## 📖 Использование

### Базовое использование

```bash
# Скомпилировать программу на C
./zygote-cc input.c

# С указанием выходного файла
./zygote-cc input.c -o output.s

# Затем ассемблировать и слинковать полученный файл
as output.s -o output.o
ld output.o -o program
./program
```

### Тестирование с примерами

```bash
# Создать примеры (если их нет)
make examples

# Протестировать компилятор
make test

# Запустить скомпилированные примеры
make run-examples
```

### Отладка

```bash
# Собрать с отладочной информацией
make debug

# Запустить через GDB
gdb ./zygote-cc
```

## 🔧 Технические детали

### Соглашения о вызовах

- Следует System V ABI для x86_64
- Параметры: %rdi, %rsi, %rdx, %rcx, %r8, %r9
- Возврат значений: %rax
- Сохранение регистров: %rbx, %r12-r15

### Синтаксис ассемблера

- AT&T синтаксис (источник, назначение)
- Префиксы регистров: %
- Префиксы констант: $
- Суффиксы размера: b (byte), w (word), l (long), q (quad)

### Ограничения

- Только целочисленный тип int
- Нет поддержки массивов и указателей
- Ограниченная поддержка операторов управления потоком
- Простое управление памятью
- Только одна единица трансляции
