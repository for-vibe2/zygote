# Быстрый старт - Zygote C Compiler

## Что это?

Примитивный C компилятор, написанный на чистом ассемблере x86_64. Образовательный проект для изучения компиляторов и низкоуровневого программирования.

## Установка

### Требования
- Linux x86_64
- GNU Assembler (as)
- GNU Linker (ld)
- GNU Make

### Проверка зависимостей
```bash
# Проверить наличие нужных инструментов
which as ld make

# Версии
as --version
ld --version
make --version
```

### Сборка
```bash
# Собрать компилятор
make

# Результат - исполняемый файл zygote-cc
ls -lh zygote-cc
```

## Первая программа

### 1. Создайте файл test.c
```c
int main() {
    return 42;
}
```

### 2. Скомпилируйте (когда будет полностью реализовано)
```bash
./zygote-cc test.c -o test.s
```

### 3. Соберите и запустите
```bash
as test.s -o test.o
ld test.o -o test
./test
echo $?  # Должно вывести 42
```

## Изучение кода

### Порядок изучения

1. **lexer.s** - начните здесь
   - Простая токенизация
   - Понятная логика
   
2. **parser.s** - затем парсер
   - Построение AST
   - Рекурсивный спуск
   
3. **codegen.s** - генерация кода
   - Обход AST
   - Вывод ассемблера
   
4. **main.s** - главный драйвер
   - Связывает все вместе
   - Ввод-вывод файлов

## Отладка

### Использование GDB
```bash
# Собрать с отладочными символами
make debug

# Запустить в отладчике
gdb ./zygote-cc

# В GDB
(gdb) break main
(gdb) run test.c
(gdb) step
```

### Проверка ассемблерного кода
```bash
# Посмотреть сгенерированный код
cat output.s

# Дизассемблировать объектный файл
objdump -d file.o
```

## Ограничения

⚠️ **Текущие ограничения:**
- Размер входного файла: 4KB
- Только функция main
- Только тип int
- Базовое подмножество C
- Нет оптимизаций

## Решение проблем

### Ошибки компиляции
```bash
# Проверить синтаксис ассемблера
make validate

# Пересобрать с нуля
make clean all
```

### Segmentation fault
- Нормально для примитивной реализации
- Проверьте размеры буферов
- Убедитесь что входной файл < 4KB
